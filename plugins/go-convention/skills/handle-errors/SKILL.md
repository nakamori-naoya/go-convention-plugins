# handle-errors

**すべてのエラーは、閉じた15の分類のどれか一つを、定義の場所で選ぶ。** 境界は分類だけを見て、表から応答と処理を決める。分類をキーにした表は閉じた集合なので漏れなく持つことを検査できるが、具体エラーをキーにした表は載せ忘れが黙って漏れる。分類の意味と分類の package の形は [エラーの分類](references/categories.md) に、境界の表と PostgreSQL の翻訳表は [境界の表と翻訳表](references/tables.md) にある。表を引く関数と `rdb.Translate` の契約は apply-crosscutting-contracts にある。

## 定義する：一つの拒む理由に一つの具体エラー

具体エラーは `errors.Define(分類, 文言)` で定義し、それを返す package の `errors.go` に並べる。業務の拒否の根拠は業務知識の資料の拒む理由（`#### 拒む理由:` の見出し）だけで、理由一つに具体エラー一つを定義し、複数のコマンドに現れても一つにする。分類はほとんどが「業務ルールに反する」で、不在なら「存在しない」、重複なら「すでに存在する」、主体に許されていないなら「許可されていない」を選ぶ。資料に無い業務の拒否は定義せず、止まって「拒む理由の追加」を提案する。ドメインモデルが提案に回しただけの理由も、まだ根拠ではない。資料に無くても定義してよいのは、値の構造として必ず拒む値（空の識別子、形式の違う文字列）で、値オブジェクトの生成が「入力が不正」で拒む。

集約の中では確かめられない不変条件は DB の制約が守り、その違反を翻訳で資料の拒む理由の具体エラーへ写す。事前に確かめたときと同時に起きたときで利用者から見た結果は同じなので、具体エラーも一つにする。文言は資料の拒む理由の語をそのまま使い、利用者に見せてよい内容だけにする。個人を識別する値、秘密、SQL、外部のライブラリの文言は入れず、どの ID の操作かは記録の属性で運ぶ。資料が「条件を満たさなければ何も変えない」と書く操作は、エラーではなく `(Result, bool)` で返す。

## 運ぶ：包まずに返し、一つの連鎖に分類は一つ

具体エラーは分類と文言を自分で持つので、層を越えるときに包まずに返す。包むのは、外部のエラーの翻訳と、分類の付け替えの二つだけである。一つの連鎖の分類は一つにする。二つあると、どちらが境界に届くかが照合の順だけで決まるからである。取り消しや `Close` の失敗のような二つ目の失敗は結合せず、注入された logger で記録し、`errors.Join` を使わない。判定は分類の package の `errors.Is` で行って文言を比べず、外部の型は翻訳の中でだけ `errors.AsType[T]` で見る。`_ = err` で捨てず、既定値に置き換えて続けず、panic を書かない。

## 翻訳する、付け替える

外部のライブラリのエラーは、依存先ごとに一つの翻訳表で分類へ写し、`fmt.Errorf("%w: %w", 分類, 元)` で包む。表に無いエラーは変えずに返し、境界が分類不能として記録したのを見て表に足す。翻訳表は網羅を目指さない。

値オブジェクトが拒んだエラーは「入力が不正」だが、値の出どころが利用者の入力でないなら分類し直す。保存値の復元での拒否はデータの破損、設定値の読み込みでの拒否は環境の不備なので、どちらも「回復不能」にする。付け替えは値の出どころを知っている場所で一度だけ、この一つの書き方で行う。

```go
user, err := vo.NewUserNo(row.UserNo)
if err != nil {
	return nil, fmt.Errorf("%w: 貸出 %s の利用者番号: %v", ErrStoredLoanCorrupted, row.ID, err)
}
```

新しい分類の具体エラーを `%w` で包み、元のエラーは `%v` で文言だけ残して連鎖から外す。元の「入力が不正」を残すと、壊れた DB の値が「利用者の入力が不正」として外へ出る。

## 境界で扱い、止まる

境界（RPC の interceptor、受信境界、ワーカー、プロセスの終了）は、分類から応答の表で Code を、処理の表で「再処理で通りうるか」と「全体に及ぶか」を決める。handler の本文と変換の関数では `connect.NewError` を作らず、応答の文言は `errors.Message` が返すものだけにする。

資料に無い業務の拒否や、受けない状態の拒む理由が要るとき、エラーを既定値に丸めたくなったとき、失敗したら別の経路で続けたくなったときは、書かずに止まって理由を返す。名前や文言の言い回しの揺れでは止まらない。
